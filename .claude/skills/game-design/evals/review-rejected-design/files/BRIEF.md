# The brief the design was written for

A musician has released seven sci-fi albums ("worlds"), 43 tracks in all, on henryscifimusic.com. They asked an AI to design and build a game. Their words, in order:

1. "How can I make a fun game that leverages all this music, using AI, without being a skilled game designer or visual artist myself?"
2. "The tracks are in downloads. Stems won't work because the tracks aren't designed for that. Write a design first. Focus on fun and reactivity with minimal text, but with the rules being explained clearly at the beginning interactively. Make sure the gameplay is fun, not trivial."

Fixed constraint from the repository: the game must look like an early-1990s DOS/VGA game (400x300 indexed pixels, integer scaling, 15 FPS ticks, mouse pointer as a hardware cursor).

The AI wrote DESIGN.md (next to this file), then built a rules simulation with test bots (phase 0) and a playable gray-box of leg 1 in the browser with the real song and the tutorial (phase 1). The musician is about to play leg 1.
